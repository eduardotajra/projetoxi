[ atlas/registro — projeto ix ]
Sobre a Origem

O Projeto IX foi concebido antes da primeira edição do jornal.
Não como conteúdo. Como intenção.

Nove era o número escolhido para representar o que ficou entre os dias.
Não o nono dia. Não a nona palavra. Apenas o conceito de lacuna.

O que foi construído em torno disso não tem nome nos registros oficiais.
Tem apenas uma série de entradas espalhadas,
esperando quem soubesse onde procurar.

Cada fragmento foi colocado num lugar específico por um motivo.
O primeiro estava visível para quem quisesse ver.
O último estava onde ninguém disse para procurar.

Entre eles: uma chave que abria outras coisas.
Um número que o jornal nunca imprimiu.
Uma sentinela que aparecia na hora certa.
Um reflexo. Um erro que não era erro.
Uma marca no lugar mais visitado.
Uma assinatura para humanos.
Uma porta que era o próprio número.

O projeto foi concluído exatamente como foi planejado.
O arquivo está aberto para quem chegou até aqui.

— Registro interno · IX

O Que Vem Depois

Toda busca termina em algum lugar.
Esta terminou aqui.

Mas o arquivo não se encerra com um fragmento revelado.
O arquivo é contínuo. Ele registra enquanto existe alguém para registrar.

O que você trouxe para este lugar foi atenção.
Atenção é rara. A maioria passa por cima sem olhar.
Você parou. Você leu. Você procurou.

O Projeto IX agora é parte do registro permanente do Atlas.
Treze fragmentos catalogados.
Treze caminhos documentados.
Um espaço entre os dias, finalmente nomeado.

O jornal vai continuar.
As edições vão aparecer e desaparecer.
Mas o IX vai existir entre todas elas — sempre.

Obrigado por ter chegado a tempo.

📄 RELATORIO_LACUNA.doc — Atlas OS
Classificado
[ relatório de campo — a lacuna ]
O Fragmento Sem Endereço

O décimo terceiro fragmento foi o mais difícil de esconder.
Não por complexidade — mas por localização.

Ele não está vinculado a nenhum link. Não está indexado.
Não tem referência direta em nenhuma página do jornal.

Ele existe em /ix.

Para chegar lá, era necessário entender três coisas:
Primeiro, que havia uma pista no arquivo de registro — "o número do projeto é o único mapa".
Segundo, que o número do projeto é IX.
Terceiro, que /ix era a porta.

Dentro da página, no código-fonte, estava escrito LPCAND.
Não em português. Em cifra Vigenère.
A mesma chave usada no fragmento dois: APAGADO.

LPCAND decifrado com APAGADO resulta em: LACUNA.

O fragmento estava onde ninguém disse para procurar.
Mas você procurou mesmo assim.

— Relatório de campo · LACUNA · XIII
